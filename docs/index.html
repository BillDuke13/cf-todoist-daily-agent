Todoist Daily Agent

Plan a focused day from a single sentence

Type or speak what you want to get done. The agent decides whether you asked for a reminder, a multi-step plan, or a meal plan, then pushes the resulting tasks straight into your Todoist account through the Model Context Protocol — all on Cloudflare's edge.

What it does

The Todoist Daily Agent turns one natural-language prompt into a short, well-shaped task list inside Todoist. There is no manual form to fill in, no priority dropdown to remember — the assistant maps everything (title, description, priority, project, labels, due time) to the public Todoist schema for you and pushes it through the official Todoist Model Context Protocol endpoint.

One textarea, one click

Describe what you want to plan. The browser detects your timezone, the worker validates the request, and the streaming UI surfaces every step (intent, plan, Todoist sync) as it happens.

Voice in, plan out

Tap Use voice input to record up to 60 seconds. Whisper Large v3 Turbo transcribes the clip, overwrites the prompt, and submits the plan in a single motion.

Intent-aware planning

Asking for a reminder yields one task. Asking for a meal plan yields meals across the days you mentioned. Asking for a multi-step day yields ordered steps with time anchors.

Edge-first runtime

Authentication, AI inference, and Todoist MCP traffic all run on Cloudflare's network. There is no separate API server — the Worker is the API.

How a request flows

  1. You describe your day. The single dialog on the home page captures one prompt and your timezone, then POSTs to /plan.
  2. Intent classification. Workers AI runs @cf/openai/gpt-oss-120b at high reasoning effort to decide whether you asked for a single reminder, a multi-step plan, a recipe plan, or a general plan.
  3. Todoist metadata discovery. The worker connects to the Todoist MCP server, lists its tools, and pulls the live catalog of projects and labels so the model only references real ones.
  4. Task generation. @cf/openai/gpt-oss-20b produces a JSON-schema constrained plan, tailored to the detected scenario, with properly mapped priorities (Todoist's 4 = P1 convention is handled for you).
  5. Todoist sync. Each task is pushed through the MCP add-task or add-tasks tool. The UI streams a status badge per task (pending, created, or failed) and a final summary with counts and elapsed time.

Endpoints at a glance

Method & path Purpose Format
POST /plan Generate a plan and push it into Todoist. NDJSON stream of typed events.
OPTIONS /plan CORS preflight. 204 No Content.
POST /api/transcribe Transcribe a short voice clip used as the prompt. JSON { text, language? }.
OPTIONS /api/transcribe CORS preflight. 204 No Content.

The full request and response schemas — including the streaming event contract — live in openapi/plan.yaml.

Getting started

You need a Cloudflare account with Workers AI enabled and a Todoist token approved for the MCP beta. Then:

pnpm install
# create .dev.vars at the repo root with the secrets listed below
pnpm preview                     # OpenNext build + Wrangler preview

For day-to-day frontend tweaks pnpm dev is faster, but it cannot reach Workers AI or Todoist MCP. Use pnpm preview (or wrangler dev) when you want the full integration.

Required secrets

Name What it does
BASIC_AUTH_USER Username for the HTTP Basic Auth gate in src/proxy.ts.
BASIC_AUTH_PASS Password for the same gate.
TODOIST_TOKEN Bearer token for the Todoist MCP server.
TODOIST_MCP_URL MCP endpoint. Defaults to https://ai.todoist.net/mcp.
FRONTEND_ORIGIN One or more comma-separated origins allowed to reach /plan and /api/transcribe.
DEBUG_EVENTS Set to "true" to receive debug.* NDJSON lines and verbose error detail. Defaults to off.
